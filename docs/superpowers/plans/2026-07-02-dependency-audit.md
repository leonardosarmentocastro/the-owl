# Dependency Audit & Hardening Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Apply the remaining safe dependency updates to `the-owl`, close the one low-severity transitive vuln, standardize example lockfiles on pnpm, add dependabot governance, and prove the library + all three examples still work end-to-end.

**Architecture:** Four sequential tasks on branch `chore/dependency-audit`: (1) root minor/patch updates + `npm audit fix`, (2) example lockfile reconciliation, (3) new `.github/dependabot.yml`, (4) full verification gate across library and examples. No source refactoring; the only code artifact authored is the dependabot config.

**Tech Stack:** npm (root + lockfile), pnpm (examples), Vitest 4, tsup, Vite 8, TypeScript 6, Express 5, Node ≥24, GitHub dependabot.

## Global Constraints

- **Safe updates only** — minor/patch. **No major-version chasing.** (Any major that appears, e.g. `@types/node` 26.x, is deferred to a dependabot PR, not applied here.)
- **Branch, never `master`** — all work lands on `chore/dependency-audit` (per AGENTS.md).
- **Examples use pnpm** — do not switch them to npm; `build:the-owl` scripts already call `pnpm install`.
- **Stop-on-failure** — if any verification step fails, stop and diagnose; do not force through breakage.
- **Node ≥24** engine floor; the shipped library must remain unaffected by dev-only vulns.
- Exact safe update targets (verified 2026-07-02 via `npm outdated`):
  `vite` → 8.1.3, `@vitejs/plugin-react` → 6.0.3, `lucide-react` → 1.23.0,
  `@types/node` → 25.9.4 (in-range patch; 26.1.0 is a major, deferred).

### Task 3: Add dependabot governance config

**Files:**
- Create: `.github/dependabot.yml`

**Interfaces:**
- Consumes: nothing.
- Produces: a weekly grouped-update policy for root + all three example directories.

- [ ] **Step 1: Write the dependabot config**

Create `.github/dependabot.yml` with exactly:

```yaml
version: 2
updates:
  - package-ecosystem: "npm"
    directory: "/"
    schedule:
      interval: "weekly"
    open-pull-requests-limit: 5
    groups:
      minor-and-patch:
        update-types:
          - "minor"
          - "patch"

  - package-ecosystem: "npm"
    directory: "/examples/01-minimal"
    schedule:
      interval: "weekly"
    open-pull-requests-limit: 5
    groups:
      minor-and-patch:
        update-types:
          - "minor"
          - "patch"

  - package-ecosystem: "npm"
    directory: "/examples/02-elaborate"
    schedule:
      interval: "weekly"
    open-pull-requests-limit: 5
    groups:
      minor-and-patch:
        update-types:
          - "minor"
          - "patch"

  - package-ecosystem: "npm"
    directory: "/examples/03-site-output-dir"
    schedule:
      interval: "weekly"
    open-pull-requests-limit: 5
    groups:
      minor-and-patch:
        update-types:
          - "minor"
          - "patch"
```

- [ ] **Step 2: Validate YAML parses**

Run: `node -e "const fs=require('fs');const s=fs.readFileSync('.github/dependabot.yml','utf8');console.log('lines:',s.split('\n').length); if(!s.includes('version: 2')) throw new Error('missing version');console.log('ok')"`
Expected: prints `lines: ...` then `ok`. (If a YAML linter such as `yamllint` is available, run it too; otherwise this parse check suffices.)

- [ ] **Step 3: Commit**

```bash

Co-Authored-By: Claude Opus 4.8 <noreply@anthropic.com>"
```
